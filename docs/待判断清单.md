## 我目前的分析（**未验证**，仅供参考）

按 `src/core/rules.ts` 逐条读过的静默返回分支：

- `requestPlayCharacter`（登场）**无提示的 return 只有三处**：409（非主阶段/战斗中）、
  **413（这张卡不在行动方手牌里）**、416（不是角色卡）。机器人只会在"主阶段 + 手牌里的角色卡"
  时给出登场按钮，所以 409/416 基本可排除，**嫌疑集中在 413**。
  而 413 的典型成因是"动作参数里的卡已经不在手牌了"——那属于**机器人拿了过期引用（工具问题）**，
  不是玩家会遇到的情况。
- `requestDeclare`（宣言）、`requestPlayArea`（配置エリア）同理，需要各读一遍它们的静默分支。

也就是说：**这批现象很可能仍然是工具侧的问题**，但必须用复现流水逐条确认（看那条 op 的参数
引用的卡当时是否真在场上/手牌），我不能凭"很可能"就写成结论。
