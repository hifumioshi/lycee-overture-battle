# 🎴 Lycee Overture 网络对战平台 — 需求确认书 v1.0

> 本文档是项目需求确认书，由用户与开发助手沟通确认后定稿（2026 年）。

## 一、项目概况

| 项目 | 内容 |
|---|---|
| 软件名称 | Lycee Overture 对战平台（工作名） |
| 软件形态 | Windows 10 桌面程序（双击运行 exe） |
| 核心玩法 | 双人网络对战，完整战场 |
| 目标用户 | Lycee 爱好者圈内分享 |
| 技术路线 | Electron + React + TypeScript |

## 二、核心功能

1. **双人网络对战**（互联网联机）
2. **完整战场布局**：牌堆、手牌、场上区域（前/后列）、EX 区、费用区、破弃区等
3. **卡牌数据管理**：卡牌数据库 + 卡图显示（日文原文卡文）
4. **中文操作界面**，卡牌文本保持日文原文
5. **房间联机**：初期借用 Steam 测试 AppID（480）走 Steam P2P；网络层做成可插拔设计，后期可平滑切换自建服务器

## 三、规则自动化（用户要求：全部自动）

- **基础规则 100% 全自动**：回合流程、EX 判定、行动/待机（アクト）、攻击/防御/交战、伤害、破弃/break、胜负判定
- **卡牌特殊效果全自动**：通过"效果脚本系统"分批实现（长期目标覆盖全部卡牌；先覆盖主流效果类型，逐步扩展）
- 系统强制规则执行，不允许非法操作

## 四、卡牌数据与图片

| 项目 | 内容 |
|---|---|
| 文字数据 | 官方站 CSV 接口 `https://lycee-tcg.com/card?output=csv`（已验证可用，数据为最新卡池） |
| 卡图 | 官方站 `https://lycee-tcg.com/card/image/{卡号}.png`（已验证可用） |
| 首批范围 | 先几十张测试卡跑通，之后逐步扩充至全部 |
| 版权注意 | 卡图仅供圈内个人使用，不公开贩卖分发；不提供大规模卡图打包分发 |

## 五、界面与交互

- 中文操作界面 + 日文卡文
- 卡牌点击/拖拽操作、卡面放大查看
- 场上状态直观显示（横置/待机等）

## 六、联机方案（初期）

- 方案：借用 Steam 测试 AppID（480）走 Steam P2P 联机
- ⚠️ 硬性要求：双方需安装并登录 Steam 客户端
- 网络层抽象设计（可插拔 Transport），后期随时切换到自建房间服务器
- 内置直连模式兜底

## 八、已知风险（用户已知情确认）

1. 借用 Steam 测试 AppID 属于灰色地带，仅作初期方案；若 Steam 限制，通过抽象层快速切换自建服务器
2. 卡图版权：仅供圈内个人使用
3. 全卡效果自动化是长期工程，但保证每个阶段都能实际游玩
4. 官方数据接口若变动，需要同步更新数据工具
